# Peek

Расширение для Chrome, которое разворачивает превью в списке диалогов ВКонтакте:
больше строк текста и несколько последних сообщений вместо одной обрезанной строки.

Лендинг и сборка: https://b-on-g.github.io/peek/

Что и зачем — в [PRD.md](./PRD.md).

## Установка из исходников

```bash
# собрать не надо, ext/ — обычный MV3 без сборки
open chrome://extensions   # включить «Режим разработчика»
# «Загрузить распакованное расширение» → выбрать папку ext/
```

Дальше открыть https://vk.ru/im и обновить страницу.

## Устройство

- `ext/` — само расширение, MV3, без сборки и без зависимостей.
    - `content.js` — находит строки диалогов и снимает обрезку с превью.
    - `inject.js` — page world, снимает токен из запросов веб-клиента ВК к `api.vk.com`.
    - `background.js` — ходит в API пачками через `execute`, держит токен в `storage.session`.
    - `popup.html` — настройки: тумблер, строки, количество сообщений.
- `app/` — лендинг на $mol, из него собирается GitHub Pages.

Превью ищется не по классам ВК, а по вычисленным стилям: берётся элемент, который браузер
реально обрезает. Так правка переживает редизайн вёрстки, а если ничего не нашлось,
расширение просто ничего не делает.

## Разработка лендинга

```bash
cd /path/to/mam && npm start
# http://localhost:9080/bog/peek/app/-/test.html
```

## Сборка

```bash
npx mam bog/peek
```

## Деплой

Пуш в `main` → GitHub Actions собирает лендинг, кладёт рядом `peek.zip` со свежим
расширением и публикует на GitHub Pages.
