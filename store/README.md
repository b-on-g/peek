## Вкладка «Описание»

**Название**

```
Peek — больше строк в списке диалогов ВК
```

**Краткое описание** (до 132 символов)

```
Разворачивает превью в списке диалогов ВКонтакте: сообщение видно целиком, а не одной обрезанной строкой.
```

**Подробное описание**

```
ВКонтакте показывает в списке диалогов одну обрезанную строку последнего сообщения. Чтобы понять, о чём речь, приходится заходить в каждый диалог по очереди.

Peek разворачивает превью прямо в списке.

• Больше строк. От одной до десяти, по умолчанию пять. Длинное сообщение видно целиком, не открывая переписку.
• Тумблер. Одно нажатие возвращает штатный вид ВКонтакте, удалять расширение не нужно.

Настройки меняются в один клик по иконке и применяются сразу, страницу перезагружать не нужно.

Работает на vk.ru и vk.com, в списке всех диалогов.

Что с данными: у расширения нет сервера, нет аккаунтов и нет аналитики. Оно не делает ни одного сетевого запроса и ничего никуда не отправляет — только меняет оформление уже открытой у вас страницы. Настройки хранятся в браузере.

Исходный код открыт: https://github.com/b-on-g/peek
```

**Категория:** Рабочие процессы и планирование (Workflow & Planning)

**Язык:** русский

## Вкладка «Конфиденциальность»

**Единственное назначение** (single purpose)

```
Peek показывает больше текста в списке диалогов ВКонтакте.

ВКонтакте выводит в списке только одну обрезанную строку последнего сообщения, из-за чего, чтобы понять, о чём диалог, приходится открывать его целиком. Расширение снимает с превью ограничение по высоте и показывает столько строк, сколько выбрал пользователь.

Больше расширение не делает ничего: оно не меняет другие страницы, не добавляет кнопок и элементов интерфейса, не обращается к API ВКонтакте, не отправляет сообщений от имени пользователя, не показывает рекламу и не собирает статистику. Работает только в списке диалогов на vk.ru и vk.com.
```

**Обоснование разрешения `storage`**

```
В chrome.storage.sync хранятся только настройки самого расширения: включено оно или нет и сколько строк показывать в превью (от 1 до 10). Синхронизируемое хранилище выбрано, чтобы пользователю не приходилось задавать эти два значения заново после перезапуска браузера и на каждом устройстве.

Тексты сообщений, списки контактов и любые другие пользовательские данные в хранилище не записываются.
```

**Обоснование доступа к сайтам (host permissions)**

```
Расширение работает исключительно на ВКонтакте, поэтому запрошены только домены самого сервиса.

*://vk.ru/*, *://*.vk.ru/*, *://vk.com/*, *://*.vk.com/* — контент-скрипт встраивается в страницу списка диалогов (/im), находит элемент превью и снимает с него ограничение по количеству строк. Это и есть единственная функция расширения, без доступа к этим доменам она невозможна. Шаблоны с поддоменами нужны потому, что мессенджер ВКонтакте работает и на основном домене, и на поддоменах сервиса.

Никаких других доменов расширение не запрашивает. Сетевых запросов оно не делает вообще, включая запросы к самому ВКонтакте.
```

**Обоснование удалённого кода** (remote code)

Выбрать «Нет, я не использую разрешение "Удаленный код"». Если поле обоснования появится:

```
Весь исполняемый код входит в пакет расширения. Скрипты с внешних адресов не загружаются, eval и new Function не используются.
```

**Какие данные собираются**

Не отмечать ничего. Расширение не собирает и не передаёт никаких данных: оно не делает сетевых запросов, не копирует текст сообщений и хранит только две собственные настройки.

Отдельно про «Личную коммуникацию» и «Содержимое сайтов»: расширение находит на странице элемент превью, но берёт у него только вычисленные стили и ширину, а сам текст не считывает и никуда не переносит — он просто перестаёт быть обрезанным на том же месте, где и был.

**Три обязательные галочки** — для этого расширения все три верны:

1. Не продаю и не передаю данные третьим лицам вне утверждённых случаев.
2. Не использую и не передаю данные для целей, не связанных с назначением расширения.
3. Не использую и не передаю данные для оценки кредитоспособности или выдачи займов.

## Публикация

Видимость: **общедоступное** (Public). Регионы: все.

## Чего ждать от ревью

Заявка простая: одно разрешение `storage`, доступ только к доменам ВКонтакте, никаких сетевых запросов, сбора данных и удалённого кода. Такое обычно проходит быстро.
