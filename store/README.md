## Вкладка «Описание»

**Название**

```
Peek — больше строк в списке диалогов ВК
```

**Краткое описание** (до 132 символов)

```
Разворачивает превью в списке диалогов ВКонтакте: больше строк текста и несколько последних сообщений вместо одной строки.
```

**Подробное описание**

```
ВКонтакте показывает в списке диалогов одну обрезанную строку последнего сообщения. Чтобы понять, о чём речь, приходится заходить в каждый диалог по очереди.

Peek разворачивает превью прямо в списке.

• Больше строк. От одной до десяти, по умолчанию пять. Длинное сообщение видно целиком, не открывая переписку.
• Несколько последних сообщений. От одного до пяти, по умолчанию два. Видно, чем закончился разговор и кто написал последним.
• Тумблер. Одно нажатие возвращает штатный вид ВКонтакте, удалять расширение не нужно.

Настройки меняются в один клик по иконке и применяются сразу, страницу перезагружать не нужно.

Работает на vk.ru и vk.com, в списке всех диалогов.

Что с данными: у расширения нет сервера, нет аккаунтов и нет аналитики. Оно ничего никуда не отправляет. Прошлые сообщения запрашиваются у API ВКонтакте тем же способом, каким это делает сам сайт в вашей вкладке, и дальше вкладки не уходят. Настройки хранятся в браузере.

Исходный код открыт: https://github.com/b-on-g/peek
```

**Категория:** Рабочие процессы и планирование (Workflow & Planning)

**Язык:** русский

## Вкладка «Конфиденциальность»

**Единственное назначение** (single purpose)

```
Показывать больше текста в списке диалогов ВКонтакте: снимать обрезку с превью и выводить несколько последних сообщений диалога.
```

**Обоснование разрешения `storage`**

```
Хранит три настройки расширения: включено или нет, сколько строк показывать, сколько последних сообщений показывать. Больше ничего в хранилище не пишется.
```

**Обоснование доступа к сайтам (host permissions)**

```
Расширение работает только на страницах ВКонтакте. Доступ к vk.ru и vk.com нужен, чтобы изменить разметку списка диалогов и снять с превью обрезку. Доступ к API ВКонтакте (web.api.vk.ru, api.vk.com) нужен, чтобы запросить несколько последних сообщений диалога, когда пользователь включил такой режим. Никаких других адресов расширение не запрашивает.
```

**Обоснование удалённого кода** (remote code)

```
Нет, удалённый код не используется. Весь код входит в пакет расширения.
```

**Какие данные собираются**

Отметить два пункта, остальные оставить пустыми:

- ✅ **Аутентификационные данные** — расширение считывает токен доступа из запросов, которые страница ВКонтакте отправляет сама, и использует его только для обращения к API ВКонтакте. Токен лежит в памяти сессии и стирается при закрытии браузера.
- ✅ **Личные сообщения** — расширение читает текст последних сообщений, чтобы показать их в списке. Тексты живут в памяти открытой вкладки и никуда не отправляются.

Не отмечать: сведения о личности, состояние здоровья, финансы, местоположение, история посещений, действия пользователя, содержимое сайтов.

**Три обязательные галочки** — для этого расширения все три верны:

1. Не продаю и не передаю данные третьим лицам вне утверждённых случаев.
2. Не использую и не передаю данные для целей, не связанных с назначением расширения.
3. Не использую и не передаю данные для оценки кредитоспособности или выдачи займов.

## Публикация

Видимость: **общедоступное** (Public). Регионы: все.

## Чего ждать от ревью

Заявка содержит доступ к личным сообщениям и к токену — на такое смотрят внимательнее обычного, первая проверка может занять несколько дней вместо часов. Если попросят сузить разрешения, самый быстрый ответ — выпустить версию только с разворачиванием строк, без обращения к API: это отдельная сборка без `inject.js`, `background.js` и доступа к API.
